# HFT Bot for BTC/USDT Futures

## Описание проекта

Проект реализует **HFT бота** для высокочастотной торговли фьючерсами BTC/USDT.  
В основе лежит стратегия **Market Making** с использованием «Божественного Предиктора».  

Бот работает исключительно с **лимитными ордерами (Limit/Maker)**, что позволяет:
* Минимизировать торговые комиссии.
* Полностью исключить проскальзывание (slippage) при входе.
* Работать на микро-спредах.

## Математическая модель

### Основные переменные

| Переменная | Описание |
|:---        |:---      |
| `capital` | Текущий доступный капитал (USD) |
| `leverage` | Кредитное плечо позиции |
| $P_{min}$ | Нижняя граница прогноза цены (точка входа в Long) |
| $P_{max}$ | Верхняя граница прогноза цены (точка выхода из Long) |
| $V_{notional}$ | Номинальная стоимость позиции в USD |
| $Q$ | Количество базового актива (BTC) |
| $f_m$ | Комиссия биржи для Maker-ордеров |
| $C_{max}$ | Лимит максимальной позиции (ограничение ликвидности) |

### 1. Расчёт объёма позиции

### 1. Расчёт объёма позиции

$$
\text{usable\_capital} = \min\left(\text{capital}, \frac{C_{\max}}{\text{leverage}}\right)
$$

$$
V_{\text{notional}} = \text{usable\_capital} \cdot \text{leverage}
$$

$$
Q = \frac{V_{\text{notional}}}{P_{\min}}
$$

### 2. Чистая прибыль по лимитным ордерам

$$
\text{gross\_profit} = Q \cdot (P_{\max} - P_{\min})
$$

$$
\text{total\_fees} = V_{\text{notional}} \cdot (2 \cdot f_{m})
$$

$$
\text{net\_profit} = \text{gross\_profit} - \text{total\_fees}
$$

### 3. Минимальный рентабельный спред

Бот входит в сделку только при условии, что потенциальная прибыль перекрывает комиссии и заданный порог:

$$
\frac{P_{\max} - P_{\min}}{P_{\min}} \ge (2 \cdot f_m) + \text{min\_profit}
$$

> **Note:** Проскальзывание (slippage) в данной модели равно 0.

### 3. Минимальный рентабельный спред

Бот входит в сделку только при условии:

$$
\frac{P_{max} - P_{min}}{P_{min}} \ge (2 \cdot f_m) + \text{min\_profit}
$$

## Ограничения и риски

1. **Execution Latency** — сетевая задержка (5–50 ms). Для HFT критично использование co-location.
2. **Position Limits** — ограничения биржи на максимальный размер позиции и плечо.
3. **API Rate Limits** — лимиты Binance (1200 весов в минуту). Требуется оптимизация запросов.
